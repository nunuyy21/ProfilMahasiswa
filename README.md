# Form Profil Mahasiswa - Jetpack Compose

Aplikasi Android sederhana ini dibuat untuk memenuhi tugas pembuatan **Form Profil Mahasiswa** menggunakan Jetpack Compose dengan menerapkan konsep *State*, *Event*, dan *Recomposition*.

## Fitur Aplikasi

- **Input Data Diri:** Kolom isian untuk Nama Lengkap, NIM, Program Studi, Semester, Email, dan Alamat.
- **State dan Recomposition:** Menggunakan *State* agar perubahan input pengguna dapat memperbarui tampilan pratinjau profil secara otomatis melalui mekanisme *Recomposition*.
- **Tombol Aksi:** Tombol Simpan Profil untuk mengonfirmasi data dan tombol Reset Form untuk mengosongkan kembali kolom input.

## Refleksi Implementasi

Bagian yang paling menantang dalam pengerjaan tugas ini adalah memahami alur pengelolaan *State* dan proses *Recomposition* pada Jetpack Compose. Saya perlu memastikan bahwa perubahan input pengguna dapat memperbarui tampilan pratinjau profil secara otomatis. Melalui tugas ini, saya belajar bahwa perubahan UI dapat dikelola melalui perubahan *State* tanpa harus mengubah tampilan secara manual.
